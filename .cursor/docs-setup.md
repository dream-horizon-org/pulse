# Cursor @Docs Setup

Cursor's `@Docs` feature lets you reference indexed documentation directly in chat and Composer.
These docs are stored locally in Cursor (not in the repo), so each team member must add them manually.

## How to Add

1. Open **Cursor Settings** → **Features** → **Docs**
2. Click **Add new doc**
3. Paste each URL below and let Cursor index it
