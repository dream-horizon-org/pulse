# Module 6 — Build & Distribution

**Goal:** Produce production-ready npm packages and CDN artifacts with correct entry points, TypeScript types, and a fully automated publish pipeline.

**Prerequisites:** Modules 1–5 feature-complete and passing tests.

---

## Scope

**In:**
- `tsup` build config: ESM + CJS + UMD outputs for all entry points
- TypeScript declaration files
- npm package `@dreamhorizon/pulse-web` with correct `exports` map
- CDN build (minified UMD) uploaded to S3 + CloudFront
- SDK version injected at build time
- GitHub Actions: CI on PR + publish on release tag
- Bundle size budget enforcement (Bundlesize / size-limit)

**Out:**
- NPM organisation setup (assumed to exist)
- CloudFront distribution provisioning (assumed to exist; same CDN as interaction configs)

---

## Deliverable

`npm install @dreamhorizon/pulse-web` works. The CDN URL `https://cdn.pulse.io/pulse-web@1.js` serves the minified bundle. TypeScript users get full type completions. A GitHub release tag triggers the full publish pipeline.

## Implementation Steps

### 1. Build Tool: tsup

`tsup` (esbuild-based) is simpler than Rollup for this use case:

```typescript
// tsup.config.ts
import { defineConfig } from 'tsup';

export default defineConfig([
  // Core SDK
  {
    entry: { index: 'src/index.ts' },
    format: ['esm', 'cjs'],
    dts: true,
    sourcemap: true,
    treeshake: true,
    minify: false,  // consumers handle minification
    external: [],
  },
  // Framework integrations (separate bundles, tree-shakeable)
  {
    entry: {
      react:  'src/integrations/react/index.tsx',
      nextjs: 'src/integrations/nextjs/index.tsx',
      vue:    'src/integrations/vue/index.ts',
    },
    format: ['esm', 'cjs'],
    dts: true,
    external: ['react', 'react-dom', 'next', 'vue'],  // peer deps, not bundled
  },
  // CDN UMD build (self-contained, all deps inlined except rrweb)
  {
    entry: { 'pulse-web.umd': 'src/index.ts' },
    format: ['iife'],
    globalName: 'PulseWeb',
    minify: true,
    sourcemap: true,
    noExternal: [/.*/],  // bundle all deps for CDN
  },
]);
```

**Output structure:**
```
dist/
├── index.js           # ESM core
├── index.cjs          # CJS core
├── index.d.ts         # TypeScript types
├── react.js           # React integration (ESM)
├── react.cjs
├── react.d.ts
├── nextjs.js
├── nextjs.cjs
├── nextjs.d.ts
├── vue.js
├── vue.cjs
├── vue.d.ts
└── pulse-web.umd.js   # CDN build (minified, all-in-one)
```

### 3. SDK Version Injection

Version is injected at build time so it appears in the `rum.sdk.version` resource attribute:

```typescript
// src/version.ts — generated by build
export const SDK_VERSION = '__SDK_VERSION__';  // replaced by tsup define

// tsup.config.ts
define: { '__SDK_VERSION__': JSON.stringify(process.env.npm_package_version) }
```

---

### 4. Bundle Size Budget

Use `size-limit` to enforce a budget and fail CI if exceeded:

```json
// .size-limit.json
[
  {
    "name": "Core SDK (no replay)",
    "path": "dist/index.js",
    "import": "{ PulseWeb }",
    "limit": "30 kB"
  },
  {
    "name": "React integration",
    "path": "dist/react.js",
    "import": "{ PulseProvider }",
    "limit": "2 kB"
  },
  {
    "name": "CDN build",
    "path": "dist/pulse-web.umd.js",
    "limit": "80 kB"
  }
]
```

### 5. CDN Upload

Upload the UMD build to S3 on each release:

```bash
# Versioned path (immutable, long TTL)
aws s3 cp dist/pulse-web.umd.js \
  s3://pulse-cdn/pulse-web@${VERSION}/pulse-web.js \
  --cache-control "public, max-age=31536000, immutable"

# Floating major version alias (short TTL)
aws s3 cp dist/pulse-web.umd.js \
  s3://pulse-cdn/pulse-web@1/pulse-web.js \
  --cache-control "public, max-age=3600"

# Invalidate CloudFront for the floating alias
aws cloudfront create-invalidation \
  --distribution-id ${CF_DIST_ID} \
  --paths "/pulse-web@1/*"
```

SRI hash published in release notes:
```
sha384-$(cat dist/pulse-web.umd.js | openssl dgst -sha384 -binary | base64)
```

### 6. GitHub Actions CI/CD

**`.github/workflows/ci.yml`** — runs on every PR:

```yaml
jobs:
  ci:
    steps:
      - pnpm install
      - pnpm typecheck
      - pnpm lint
      - pnpm test
      - pnpm build
      - pnpm size          # fails if bundle exceeds budget
```

**`.github/workflows/publish.yml`** — runs on release tag `pulse-web@*`:

```yaml
on:
  push:
    tags: ['pulse-web@*']

jobs:
  publish:
    steps:
      - pnpm install
      - pnpm build
      - pnpm test
      - npm publish --access public       # publish to npm
      - ./scripts/upload-cdn.sh           # upload to S3 + invalidate CloudFront
      - gh release create $TAG \          # GitHub release with changelog
          --notes-from-tag
```

## Testing Cycle

### Build Verification
- `pnpm build` completes without errors
- All `dist/` entry points exist and are valid JS
- `dist/index.d.ts` exports all public types
- `size-limit` passes (bundle < budget)

### Install Smoke Test
```bash
# In a fresh project
npm install @dreamhorizon/pulse-web
node -e "const { PulseWeb } = require('@dreamhorizon/pulse-web'); console.log(typeof PulseWeb.start)"
# → "function"
```

### CDN Smoke Test
```bash
curl -I https://cdn.pulse.io/pulse-web@1/pulse-web.js
# → 200, Content-Encoding: gzip, Cache-Control: max-age=3600
```

// Should type-check cleanly

## Known Risks

- **npm organisation access**: confirm `@dreamhorizon` npm org exists and publish token is available in GitHub secrets before attempting publish.
- **Peer dependency warnings**: consumers using older React versions may see peer dep warnings. Test with React 17 and React 18.
