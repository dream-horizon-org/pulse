**Columns**


| Column         | Meaning                                                                                       |
| -------------- | --------------------------------------------------------------------------------------------- |
| **ID**         | Stable id (`ISS-###`) in this doc                                                             |
| **Kind**       | `Code` · `Spec` · `Test`                                                                      |
| **Gap**        | What is wrong or missing (technical, one line)                                                |
| **Detail**     | Why it matters, in plain English                                                              |
| **Expected**   | What should be true; SPEC ref + Android / tool comparison where relevant                      |
| **Suggestion** | Recommended action or decision, informed by industry tools (Sentry, PostHog) where applicable |
